# FolderTypeIndex

A local file organization and indexing tool for personal knowledge management.

> ⚠️ **Status**: Initial open source release (v4)

## Features

- 📁 Organize files by custom folder type rules
- 🔍 Fast local indexing without cloud sync
- 🛡️ Privacy-first: all data stays on your machine
- ⚡ Lightweight and fast

## Quick Start

```bash
# Clone the repository
git clone https://github.com/dunwood/FolderTypeIndex.git
cd FolderTypeIndex

# See examples for configuration format
ls examples/
```
