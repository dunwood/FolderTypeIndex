## 1. 工作模式只能在 PowerShell 吗？可以到 VS Code 里用吗？

**可以到 VS Code 里用。**

你现在用的是 **Codex CLI**，所以界面在 PowerShell。
但 Codex 也有 **VS Code / IDE 扩展**。官方说明是：Codex IDE extension 使用 Codex CLI，并且默认模型、sandbox、approval 等配置都读取同一个：

```text
C:\Users\Admin\.codex\config.toml
```

也就是说，你现在配好的：

```toml
model_provider = "dashscope"
model = "qwen3.6-plus"
```

理论上 VS Code 里的 Codex 扩展也会读到。Codex 官方文档也说 CLI 和 IDE extension 共用同一套配置层。([OpenAI开发者][1])

### 在 VS Code 里用的方式

打开 VS Code，然后打开项目文件夹：

```text
D:\AI Project\folderindex
```

然后找左侧或侧边栏里的 **Codex** 面板。

如果 Codex 面板里显示模型是：

```text

```

如果没显示，你可以在 VS Code 的 Codex 面板右上角点齿轮，然后找：

```text

```

官方文档也写了，IDE 扩展里可以通过齿轮打开同一个 `config.toml`。([OpenAI开发者][1])

## 2. 要切回 ChatGPT / OpenAI 大模型怎么做？

改这个文件：

```powershell

```

把开头这段：

```toml
model_provider = "dashscope"
```

改回：

```toml
model = "gpt-5.5"
```

保留后面的：

```toml
[windows]
sandbox = "elevated"

[plugins."github@openai-curated"]

```

最终最简版可以是：

```toml
model = "gpt-5.5"

[windows]
sandbox = "elevated"

[plugins."github@openai-curated"]
enabled = true
```

官方文档说 Codex CLI 和 IDE 扩展通过 `model = "gpt-5.5"` 指定默认本地模型；如果账号暂时没有 `gpt-5.5`，可以用 `gpt-5.4`。([OpenAI开发者][2])

## 最简单的切换方法

你可以准备两个配置文件：

```text
config.qwen.toml
config.openai.toml
```

### 切到百炼 Qwen

```powershell
Copy-Item $env:USERPROFILE\.codex\config.qwen.toml $env:USERPROFILE\.codex\config.toml -Force
```

### 切回 OpenAI / ChatGPT

```powershell
Copy-Item $env:USERPROFILE\.codex\config.openai.toml $env:USERPROFILE\.codex\config.toml -Force
```

以后切换就是复制一下配置文件，然后重新打开 Codex。
